# 8K-fotoprompts — facilitair en sectoroplossingen

Deze set bevat twaalf zelfstandige productieprompts: vijf voor de facilitaire routes en zeven voor de oplossingen-/sectorroutes. Iedere prompt is bedoeld als unieke vervanger van het huidige abstracte servicebeeld in `Hero → ServiceVisual`. De genoemde desktop- en mobiele exports worden uit dezelfde master gemaakt.
