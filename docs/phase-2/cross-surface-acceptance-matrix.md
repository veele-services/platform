# Phase 2 Cross-Surface Acceptance Matrix

| Capability | Backoffice | Planboard | Personnel PWA | Customer portal | Deterministic evidence |
| --- | --- | --- | --- | --- | --- |
| Assignment lifecycle | Can execute validated domain commands and see canonical state plus compatibility label. | Shows `plannable`, `partially_staffed`, `scheduled`, `in_progress` without generic overrides. | Shows only published/assigned work and valid participant actions. | Shows customer-safe projection: received, in treatment, scheduled, executed, report available, invoiced/paid. | Static lifecycle reducer tests; browser scenario for each transition. |
| Planned vs actual time | Edits planned window only through planning commands; actual correction is separate and audited. | Drag/drop changes planned window with conflict and row-count proof. | Captures own start/pause/complete actual times, including offline replay. | Sees appointment window and approved progress, not raw staff telemetry. | Unit tests for display-window priority and aggregate/labor duration. |
| Staffing and interest | Selects primary/reserve from eligible interested personnel. | Displays required/assigned/reserve counts and readiness blockers. | Shows own interest/selection/assignment status. | Hidden. | Concurrency/idempotency tests for selection and full-staffing transition. |
| Availability/eligibility | Maintains availability, leave, sickness and eligibility evidence. | Blocks conflicting assignment drops and explains planner-safe reasons. | Allows personnel availability workflow where authorized. | Hidden. | Atomic save/stale update/overlap tests. |
| Multi-person execution | Sees per-participant and aggregate execution. | Shows aggregate progress and staffing exceptions. | Each participant can seen/accept/start/pause/complete/reject per policy. | Sees customer-safe progress only. | Multi-worker Playwright flow and event projection assertions. |
| Reports/media | Reviews draft submissions and approves customer visibility. | Shows report gate state. | Creates report notes/media with offline queue semantics. | Sees approved customer-visible reports/documents only. | Media replay idempotency and approved projection tests. |
| Realtime updates | Subscribes to tenant-scoped events. | Updates cards without refresh. | Receives assignment/staffing changes while preserving offline queue. | Receives projection changes only. | Cross-surface event fixture with version monotonicity checks. |
| Account activation/recovery | Can issue/revoke access according to permissions. | Not applicable. | Credential recovery is responsive and secure. | Credential recovery is responsive and secure. | Auth challenge protocol tests and screenshots. |
| Responsive shared UI | Uses shared shells/tokens. | Keyboard and touch accessible planning controls. | Mobile-first PWA shell. | Mobile-first portal shell. | Accessibility checks and viewport screenshots. |
